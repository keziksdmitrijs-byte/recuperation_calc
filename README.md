# Калькулятор рекуперации / Rekuperācijas kalkulators

Веб‑приложение: клиент загружает план дома, задаёт масштаб и площадь, выбирает рекуператор,
расставляет коллекторы и диффузоры, рисует трубы — и получает смету с PDF.

## Состав

```
public/index.html   — всё приложение (калькулятор + админка), один статический файл
supabase/setup.sql  — таблицы, права доступа и функции в Supabase (без цен)
```

Сервер не нужен: страница статическая и работает напрямую с Supabase.

## Кто что видит

* **Клиент** получает каталог через функцию `calc_public_catalog()` — только итоговые цены (цена прайса × наценка/скидка). Цен прайса и процентов ему не отдаётся.
* **Клиент** может только *добавить* заявку (`calc_leads`) — она создаётся, когда он скачивает PDF сметы. Читать заявки он не может.
* **Администратор** (пользователь Supabase из таблицы `calc_admins`) видит заявки и меняет каталог, цены прайса, наценки и цены монтажа.
* Встроенный в `index.html` каталог содержит только итоговые цены — он используется, пока база не подключена или пуста.
* Файл с ценами прайса (`calc_seed.sql`) в репозиторий **не** добавляется.

## Настройка Supabase (один раз)

1. Supabase → **SQL Editor** → вставить и выполнить `supabase/setup.sql`.
2. **Authentication → Users → Add user**: e‑mail и пароль администратора, отметить *Auto Confirm User*.
3. В SQL Editor выполнить (со своим e‑mail):
   ```sql
   insert into public.calc_admins (user_id)
     select id from auth.users where email = 'ваш@email.lv'
     on conflict do nothing;
   ```
4. Выполнить `calc_seed.sql` (передаётся отдельно) — каталог с ценами прайса и наценками.
5. В `public/index.html` в начале скрипта указать `SUPABASE_URL` и `SUPABASE_ANON_KEY`
   (Supabase → Project Settings → API: *Project URL* и ключ *anon public*). Этот ключ публичный по назначению, доступ ограничивают права в базе.

Пока `SUPABASE_ANON_KEY` пустой, калькулятор работает в демо‑режиме: встроенный каталог, заявки не сохраняются.

## Админка

Открыть страницу калькулятора с `#admin` в конце адреса (или ссылка **Admin** вверху) и войти e‑mail/паролем администратора.

* **Pieteikumi / Заявки** — расчёты клиентов: дата, контакты, объект (площадь, объём, нужный расход), подобранный рекуператор, сумма. «Открыть» — смета с итоговыми ценами и ценами прайса, разница с прайсом, план с трубами. Статус «Новая / Обработана», удаление.
* **🔑 Mainīt paroli / Сменить пароль** — смена пароля администратора (нужен текущий пароль, новый — от 8 символов).
* **Katalogs un cenas / Каталог и цены** — НДС, запас труб, кратность, цены монтажа, наценки/скидки по типам товаров, весь каталог, импорт/экспорт Excel. «Сохранить» — изменения сразу видны клиентам.

Внешние библиотеки (pdf.js, jsPDF, html2canvas, SheetJS) подгружаются с cdnjs только когда нужны
(загрузка PDF‑плана, выгрузка PDF, импорт/экспорт Excel).

## Каталог (импорт CSV / Excel)

CSV рекуператоров AlpicAir в исходном формате (model, airflow_max_m3h, duct_diameter_mm, price_eur, subcategory) можно импортировать напрямую.

Первая строка — заголовки. Проще всего нажать в админке «Экспорт в Excel», заполнить файл и импортировать обратно.

| Колонка    | Значение |
|------------|----------|
| `type`     | `recuperator`, `collector`, `plenum` (коллектор диффузора), `diffuser`, `flex_pipe`, `rigid_pipe`, `elbow`, `grille`, `cap`, `ring`, `silencer`, `accessory` (можно и русские/латышские названия типов) |
| `sku`      | артикул |
| `name`     | название |
| `group`    | группа рекуператора для фильтра: `vertikalais`, `horizontalais`, `griestu`, `sienas` |
| `diameter` | мм. Для коллектора `0` = универсальный (75 и 90) |
| `inlet`    | коллектор — Ø подключения магистрали; коллектор диффузора — Ø диффузора (100/125/160) |
| `airflow`  | максимальный расход рекуператора, м³/ч |
| `outlets`  | число выходов коллектора / подключений коллектора диффузора |
| `length`   | гибкая труба — длина бухты (м); жёсткая — длина одной трубы (м) |
| `kind`     | для диффузора: `supply` / `extract` / `any` |
| `price`    | цена без PVN, € (за штуку / бухту) |

## План: обрезка и поворот

На шаге «План» у загруженного плана есть кнопка **✂ ⟳ (Обрезать / повернуть)**: поворот на 90° в обе стороны, точный поворот ползунком (±45°, с сеткой для выравнивания) и обрезка рамкой. Уже нарисованное на этаже (масштаб, контуры, объекты, трубы) пересчитывается вместе с планом, масштаб сохраняется.

## Сохранение проекта

Проект (все этажи, планы, расстановка, данные клиента) сохраняется в JSON‑файл кнопкой **Сохранить проект** — на шаге «План» и на шаге «Смета» рядом с «Скачать PDF». Имя файла: `rekuperacija-<клиент>-<дата>.json`. Открыть — «Открыть файл проекта» на шаге «План».

## Правила расчёта

* Площадь — сумма обведённых контуров (или ручной ввод) × высота потолка = объём. Нужный расход = объём × кратность (по умолчанию 1/ч). Рекуператоры с меньшим максимальным расходом показаны тёмными (в конце списка).
* Пропускная способность: Ø75 = 30 м³/ч, Ø90 = 50 м³/ч (меняется в админке). Отдельно для притока и вытяжки сумма должна быть не меньше нужного воздухообмена (объём × кратность), иначе — предупреждение. Минимальное число труб считается от него же.
* Коллектор: предпочитается вход того же Ø, что и патрубок рекуператора. Коллектор диффузора — по числу и Ø труб, затем диффузор подбирается под его размер (можно выбрать вручную).
* Язык: латышский по умолчанию, также английский и русский.
* Длина гибких труб — по нарисованным линиям и масштабу этажа, + запас 10 %; через стояк добавляется высота потолка. Закупка — целыми бухтами.
* Коллектор подбирается автоматически: самый маленький, у которого выходов ≥ подключённых труб нужного диаметра. Свободные выходы — заглушки.
* Перед каждым диффузором — коллектор диффузора на число подведённых труб.
* Кольца уплотнения — 2 на трубу (меняется в админке).
* Жёсткие трубы: длина по линии + запас, округление до целых труб; каждый излом линии — поворот; у каждой трубы забора/выброса — наружная решётка.
* Монтаж (без PVN): ставка за метр гибкой трубы, подключение рекуператора, вывод труб наружу — задаются в админке.
* Наценка / скидка задаётся в админке отдельно для каждого типа товара и применяется к цене прайса.
* Глушители и прочие позиции клиент добавляет сам на шаге «Смета».
